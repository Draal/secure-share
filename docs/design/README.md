# Encrypt.One — эталонные макеты первого релиза

Эти файлы — макеты из дизайн-канваса. Это эталон для вёрстки, а не код сайта.
Файлы используют синтаксис канваса: вставки `{{accent}}`, теги `<x-dc>`, `<sc-if>`,
`<helmet>`, скрипт `class Component extends DCLogic`. Переносить этот код как есть
не нужно. Брать из него нужно точные значения: цвета, размеры, отступы, радиусы,
шрифты, тексты, порядок блоков и поведение элементов.

Акцентный цвет в макетах подставляется через `{{accent}}`, по умолчанию `#0B7A5E`.
Полупрозрачный фон акцента (`{{accentTint}}`) — это тот же цвет с прозрачностью 10%.

| Файл | Экран | URL на сайте |
|---|---|---|
| `Main.dc.html` | Главная: форма секрета, «Как это работает», устройство ссылки, сценарии, вопросы, подвал | `/`, `/ru/`, `/uk/` |
| `Created.dc.html` | Ссылка готова: копирование, отправка, статус, уничтожение | `/m/<id>#<токен>` (страница отправителя) |
| `Generator.dc.html` | Генератор паролей | `/password-generator/`, `/ru/password-generator/`, `/uk/password-generator/` |
| `Recipient.dc.html` | Получатель до открытия, телефон | `/s/<id>#<ключ>` |
| `Revealed.dc.html` | Получатель после открытия, телефон | `/s/<id>#<ключ>` |
| `Gone.dc.html` | Ссылка уже прочитана или истекла, телефон | `/s/<id>#<ключ>` |
| `Brand.dc.html` | Логотип, цвета, шрифты, компоненты | — |

Все макеты сделаны на русском. Английская и украинская версии повторяют ту же структуру.
