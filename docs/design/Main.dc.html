Передайте пароль одноразовой ссылкой

Секрет шифруется прямо в вашем браузере. Получатель откроет ссылку один раз, после чего данные удаляются с сервера.

  • Шифрование AES-256 на вашем устройстве
  • Открытый исходный код

Как это работает

  1. 1

    Вставьте секрет

    Пароль, API-ключ, данные для входа или файл. Всё шифруется ещё до отправки в вашем браузере.

  2. 2

    Отправьте ссылку

    Через Telegram, WhatsApp, Signal, Viber, почту или любой другой мессенджер. В переписке останется только ссылка, а не сам пароль.

  3. 3

    Ссылка сгорает

    После просмотра данные удаляются с сервера. Открыть ссылку второй раз уже нельзя.

Почему мы не можем прочитать ваш секрет

Ключ расшифровки находится в самой ссылке, после символа #. Браузер никогда не отправляет эту часть адреса на сервер, поэтому её видите только вы и получатель.

encrypt.one/s/k7Qm2xPa Уходит на сервер. Адрес зашифрованных данных: без ключа это просто набор байтов.
#Vb3RtL9qWzE4 Остаётся у вас. Ключ расшифровки. Браузер не передаёт серверу ничего, что стоит после #.

Шифрование в браузере

Встроенный в браузер Web Crypto API и алгоритм AES-256-GCM. Никаких сторонних библиотек.

Открытый код

Весь код опубликован на GitHub. Любой может проверить, как устроено шифрование.

Ничего лишнего

Без регистрации, сторонних скриптов и трекеров. Поэтому на сайте нет и баннера про cookie.
